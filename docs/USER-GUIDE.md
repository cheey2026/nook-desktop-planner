# Nook

> 桌面一角的每日计划。

一个常驻桌面一角的小计划表：写每日计划、盯超期计划，点一下圆圈就完成任务，桌面上的透明小组件会给你一句鼓励。

## 功能

- **每日计划**：按日期安排任务，回车即添加。
- **界面语言**：默认中文，可在「设置 → Language」切成 English，主窗口与桌面组件一起生效，改完立刻切。
- **时间段**：任务可以设开始/结束时间，行内显示 `⏰ 20:30–21:00`；拖时间前会提醒。设置里可关掉组件上的时间显示。
- **到点提醒**：任务设了时间后，开始前 5 分钟和到点各提醒一次——系统通知 + 桌面组件里浮一条，不会错过。
- **长期计划**：多一个「长期」页，可以建目标（比如「三个月跑完半马」），把任务挂到目标下，进度条自动算；目标卡里能直接加任务，也能让 AI 帮你把目标拆成一组任务。
- **AI 助手（可选，用自己的 Key）**：接 DeepSeek / 通义千问 / Kimi / 智谱 或任意 OpenAI 兼容接口。能做四件事：把一段文字或一张截图识别成任务；把目标拆成未来几天的计划；一键生成周计划；每天晚上生成「今日小结」并给建议。
- **凭证验收（可选）**：可以把任务设成「需要凭证」，打勾时让你传一张截图，AI 看一眼判断是不是真做完了，通过才自动打勾。
- **粘贴即识别**：复制一段聊天记录 / 待办清单，在任意页面按 `Ctrl + V`（或点输入框旁的「识别」），自动拆成多条任务——会认出「今天 / 明天 / 后天 / 周四 / 下周 / 10月28日」这类日期、「10:00 / 下午 3 点半」这类时间，以及 `http(s)://` 链接，确认后一键加入。
- **截图识别**：复制的是一张图片（截图、聊天截图）也能识别；没配 AI 时用 Windows 自带 OCR（离线），配了 AI 就走视觉模型（看得更准）。
- **拖入文件**：把 txt / md / log / 图片直接拖到主窗口，自动识别成任务。
- **任务挂链接 / 应用**：每个任务可以关联一个网址或本机程序（如 `notion.so`、`C:\Program Files\App\App.exe`、`.lnk` 快捷方式），任务名字后面会出现一个小按钮，主窗口和桌面组件上**点一下就直接打开**。
- **超期计划**：过了日期还没完成的任务会自动归到「超期」，可以单独「顺延到今天」，也可以一键全部顺延。
- **完成动画**：点击任务前的圆圈，圆圈弹跳 + 扩散光环 + 彩色碎片，并飘出一句鼓励（太棒了 / 又搞定一件 / 干得漂亮…）。
- **桌面透明组件**：无边框、圆角、半透明，常驻桌面右上角，可拖动到任意位置。
- **桌面直接完成任务**：组件上和主窗口一样可以点圆圈完成，两边状态实时同步。
- **自选显示内容**：今天的计划 / 超期计划 / 已完成 / 未来计划 / 进度条 / 底部提示，逐项开关；还能调条数、透明度、字号、宽度、主题色、是否置顶。
- **开机自启动**：设置里一个开关，登录 Windows 后自动运行（只显示桌面组件，不弹主窗口）。
- **托盘常驻**：关闭主窗口不会退出，组件和托盘图标继续工作。

## 使用

双击桌面上的「Nook」快捷方式，或者双击文件夹里的 `Nook.exe` 启动。

> 文件夹里的 `Nook Core.exe` 是真正的主程序，`Nook.exe` 是一个很薄的启动器：它负责用干净的环境、带 `--no-sandbox` 参数把内核拉起来。**不要把内核单独双击**，也别删掉任何一个。

- 桌面组件出现后，按住**标题栏**拖动可以换位置，位置会自动记住。
- **改大小**：鼠标拖组件任意边缘（右下角有圆点提示）即可自由缩放；拖过之后就是自定义尺寸，想恢复自动高度在右键菜单或设置里重新打开「高度自适应内容」。
- **是否显示在最上层**：点标题栏上的图钉图标即可开/关，也可以在组件上点右键、或在「设置 → 窗口与启动」里切换。关掉后组件会回到桌面层，不再挡住其它窗口。
- 在组件上**点右键**有快捷菜单：显示在最上层、高度自适应内容、打开计划表、组件设置、隐藏组件。
- 组件上的 `＋` 打开主窗口添加任务，`☰` 打开计划板，`×` 隐藏组件（可从托盘再叫出来）。
- 主窗口按 `Ctrl + N` 快速聚焦输入框；`Ctrl + Alt + P` 随时唤出主窗口。
- 任务前的圆圈点一下就完成；鼠标移到任务行上，行尾还有「✓ 完成 / 顺延 / 链接 / 删除」按钮。
- **给任务挂链接或应用**：添加任务前点输入框右边「＋ 链接」（可以填网址，也可以点「选择应用 / 文件…」挑本机程序）；已经建好的任务，把鼠标移上去点行尾「链接」也能补上或修改。挂上后任务名右边会出现 `↗ notion.so`、`↗ notepad.exe` 这样的小按钮，**点它就直接打开**，桌面组件上同样能点。
- 双击任务标题可以改名，回车保存、Esc 取消。
- **给任务设时间段**：点输入框右边的「⏰ 时间」先定时间再添加；已有任务把鼠标移上去点行尾「时间」修改。设了时间就会有到点提醒。
- **长期计划**：左侧「长期」→ 右上「＋ 新建目标」，填名字和起止日期；每个目标卡下面可以直接加任务（自动挂到这个目标），也能用「🪄 帮我拆」让 AI 拆一组任务；目标卡右上角「🪄」用 AI 把目标拆成未来几天的日计划。
- **AI 周计划 / 今日小结**：今日页顶上「🪄 AI 建议」「📋 今日小结」两个按钮。AI 建议＝写一句目标让 AI 拆成任务；小结会存进本地，随时能翻。
- **识别待办**：点输入框右边的「识别」，会先弹出一个输入框——把要识别的文字粘进去（或点「从剪贴板粘贴」「选择图片」），确认后点「开始识别」，再在结果里改标题/日期/时间、删掉不要的，最后「全部添加」。不会一按就偷偷读剪贴板。
- **文件导入**：今日页顶上的「📄 文件导入」，选一个 txt / md / json / 图片，自动读出来拆成任务；把文件直接拖进窗口也可以。
- **切语言**：「设置 → Language」，中文 / English，主窗口和桌面组件一起切，默认中文。
- **粘贴识别**：把要安排的内容复制好，在主窗口任意位置（不在输入框里时）按 `Ctrl + V`，或点输入框右边的「识别」按钮，弹窗里粘文字、点「开始识别」；弹出「识别到 N 条待办」，可以改标题、改日期、改时间、删掉不要的，然后「全部添加」。粘贴的是图片时会先跑一遍系统 OCR，大约 1–2 秒。
- 桌面组件里也可以：点一下组件让它获得焦点，然后 `Ctrl + V` 粘贴文字或截图，识别到的任务会直接加进计划表。
- 主窗口右上角 `✕` 只是收起到托盘；彻底退出在「设置 → 退出程序」或托盘菜单里。

> 这个 exe 没有购买代码签名证书，首次运行时 Windows 可能提示「已保护你的电脑」，点「更多信息 → 仍要运行」即可。

## AI 助手（可选）

不配也能用全部基础功能；配了才有「识别更准、拆解、周计划、今日小结、凭证验收」。

1. 打开「设置 → AI 助手」，把开关打开；
2. 「服务商」选一个（DeepSeek / 通义千问 / Kimi / 智谱），接口地址和模型名会自动填好；用别家就选「自定义」，填 OpenAI 兼容的 Base URL（形如 `https://api.xxx.com/v1`）和模型名；
3. 填上自己的 API Key，点「保存」，再点「测试一下」——返回「可用」就成了；
4. 想用截图识别/凭证的话，「视觉模型」要填一个支持看图的模型（如 `qwen-vl-plus`、`glm-4v-flash`）；留空则图片走本机 OCR。

关于数据和费用：

- Key 只存在本机，用 Windows 自带的 safeStorage 加密后写进 `plans.json`，不上传、不进分享包；
- 只有在你点了识别/拆解/小结/凭证时，才把**那一段内容**发给你选的服务商，基础的计划功能完全不联网；
- 费用由你自己的 API 账户承担，识别一次一般几千 token，几厘钱；接口出错会退回本机识别，不会卡住。

## 数据

- 程序安装在 **`D:\Nook`**，数据保存在**程序目录下的 `data\plans.json`**（便携存放，整个文件夹拷走就能带走数据），另有一份 `plans.backup.json` 备份。
- 如果程序目录不可写（例如放进了 Program Files），会自动退回 `%APPDATA%\nook`。
- 不联网、不上传；设置页里可以直接「打开文件夹」查看。
- `data\startup.log` 记录了每次启动的时间与参数，排查启动问题时很有用。

## 开机自启动

在「设置 → 窗口与启动」里打开「开机自启动」即可，不需要管理员权限。实现方式是：

- 在系统启动文件夹里写一个 `Nook.vbs`（`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`），登录 Windows 后自动启动，并且只显示桌面组件、不弹主窗口；
- 同时尝试写系统登录项（`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`）作为双保险。

取消就是把开关关掉，或者直接删掉启动文件夹里的那个脚本（设置页里「启动文件夹 → 打开」可以一键打开该目录）。

如果之后把软件文件夹挪了位置，请在新位置重新打开这个开关一次。

## 常见问题

**双击一点反应都没有？**
先确认双击的是 `Nook.exe`（不是 `Nook Core.exe`）。启动器会先按正常方式启动，启动即崩溃时自动改用兼容模式重试一次；两次都失败会直接弹窗告诉你错误码和建议（把整个文件夹一起移动、加安全软件信任、确认 `Nook Core.exe` 还在）。弹窗都没有、进程也不在，就看 `data\startup.log` 里有没有新记录：没有记录说明进程在更早的地方就被挡住了（多半是安全软件），有记录就把它发我。

**任务后面的小按钮点了没反应？**
主窗口会弹出一条提示说明原因：网址要带 `http://` 或 `https://`，本机程序要填完整路径（点「选择应用 / 文件…」会自动填好）。

**桌面组件不见了？**
托盘图标（右下角）单击或右键 →「显示桌面组件」。

**组件挡住别的窗口？**
点组件标题栏的图钉关掉「显示在最上层」，它就会留在桌面层；或把它拖到屏幕边缘。

**粘贴识别没反应 / 认错了？**
- 识别文字时，输入框里粘贴是正常打字，要**先把光标移出输入框**（点一下空白处）再 `Ctrl + V`；或者直接用输入框旁的「识别」按钮。
- 图片识别依赖 Windows 自带的中文 OCR（大多数中文系统默认就有）。提示「没装 OCR 语言包」时，去「设置 → 时间和语言 → 语言」给中文补上「光学字符识别」组件即可。
- 识别结果只是「草稿」：标题、日期都能在弹窗里改，删掉不要的再添加。
- 一段话里如果没有任何日期，默认按「今天」加入；时间会写进任务标题（如 `10:00 提交周报`）。

**AI 相关的常见问题**
- 「测试一下」失败：先看报错。401/403 是 Key 不对或没充值；404 多半是接口地址少了或多了 `/v1`；超时就换个更快的模型或检查网络/代理。
- 想换服务商：直接换「服务商」，接口地址和模型名会自动跟着变（自己填过就不会覆盖），再改 Key 即可。
- 截图识别不准：先确认填的是**视觉模型**；仍不准就把截图裁小一点、只留关键部分。
- 完全不想要 AI：把「设置 → AI 助手」的开关关掉，所有 AI 入口会消失，识别自动回到本机 OCR。

**需求凭证的任务点圆圈没反应？**
它会打开凭证框，让你传截图。想跳过就点「先不打勾」或「直接完成」；「设置 → 默认需要凭证」关掉后，新任务就不再要凭证。

**没收到到点提醒？**
- 任务要**设了时间**才有提醒，只设日期不会提醒；
- 系统通知被关掉时，提醒只在桌面组件里浮一条（设置 → 提醒 里可以看开关）；
- Windows 的「专注助手 / 勿扰模式」会拦住通知，需要放行。

**想要更大 / 更小的组件？**
直接拖组件的边角即可；也可以在「设置 → 外观与尺寸」里用宽度滑块、或关掉「高度自适应内容」后调高度。

**想让组件更透 / 更实？**
设置 → 外观 → 背景不透明度，0.45 起。

**换电脑 / 备份**
复制整个程序文件夹即可（数据在里面的 `data` 目录）。

## 分享给别人

```powershell
node tools\package_share.js
```

产物是 `share\Nook-<版本>-win64.zip`（约 270MB，Electron 运行时占大头），对方解压到任意目录、双击 `Nook.exe` 就能用，包内附带一份 `先读我.txt`。

打包时特意做了这些处理，保证在别人的机器上也能跑：

- **不含本机数据**：`data` 目录、日志、快捷方式、自启动项都不进包，对方拿到是全新状态；
- **沙箱优先、必要时回退**：启动器先按正常方式启动（Chromium 沙箱开启），只有「启动即崩溃」的环境才自动改用 `--no-sandbox` 重试一次，正常机器不牺牲沙箱；
- **环境变量自愈**：若被其它 Electron 程序拉起、带上 `ELECTRON_RUN_AS_NODE`，程序会自己用干净环境重启；
- **路径无关**：程序目录可整体搬动，不写死安装位置；
- **只读位置也能用**：放在 Program Files 这类不可写目录时，数据自动落到 `%APPDATA%\nook`；
- **不需要管理员权限**：绿色解压即用，开机自启只写当前用户。

提醒对方两点：首次运行 Windows 可能提示「已保护你的电脑」（没有代码签名，点「更多信息 → 仍要运行」）；个别杀毒软件会对自制启动器报警，把整个文件夹加入信任即可。
